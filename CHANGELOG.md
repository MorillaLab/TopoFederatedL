# Changelog

## [2.0.0] — 2026

### Correction
- The numerical results shown in the v1.0.0 README and in version 1 of the preprint
  (arXiv:2603.04323v1) were **not produced by running this code** and are **withdrawn**.
  Every number in the revised manuscript is regenerated by `ptopofl_v2.py` with fixed seeds.

### Changed: method
- Local training now uses τ gradient steps per round. In v1, local models were re-solved to convergence each round, so training was effectively one-shot.
- The personalised cluster models are broadcast to clients and evaluated per client. In v1 they were computed but discarded.
- The descriptor:
  - is computed once, with a fixed per-client seed;
  - is averaged over 5 subsamples;
  - has 46 distinct coordinates (v1 stored two of them twice).
- The blending coefficient is calibrated from a target effective blending (closed-form result in the paper).
- Anomaly scoring uses a robust median/MAD score; cluster masses are trust-weighted.
- Topology-augmented local training is removed: its features were constant per client and had no effect.

### Changed: experiments
- Baselines implemented as published: FedProx, SCAFFOLD (option II), pFedMe, Ditto, IFCA.
- New baselines: a PACFL-style subspace baseline, plus random and oracle partitions as references.
- Synthetic generators corrected; the v1 data were linearly separable, so every method reached AUC = 1.
- Real four-hospital dataset added (Fed-Heart-Disease, FLamby site partition).
- New studies: theory checks, alignment study, corrupted clients, DP sweep with membership- and property-inference attacks, ablations, sensitivity analysis.
- The partition-quality score ρ is computed with the same sample-proportional weights for every partition.

### Added
- Unit tests that check the implementation and the main theorems on the actual code.
- GitHub Actions workflow on Python 3.10, 3.12 and 3.14.
- Colab notebook.
- LaTeX sources of the revised manuscript.

### Removed
- The v1 package (`ptopofl/`), its tests, the deep-learning notebook, and the v1 figures.
  They remain available under the tag `v1.0.0`.

## [1.0.0] — 2026
- Initial release (tag `v1.0.0`). The results reported with it are withdrawn; see above.
